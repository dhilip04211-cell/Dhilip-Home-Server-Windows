# Dhilip Home Server 0.3.1 — Windows Installer

This package now contains a real Windows installer configuration.

Final user experience:
1. Run DhilipHomeServer-Setup-0.3.1.exe
2. Install Dhilip Home Server
3. Desktop and Start Menu shortcuts are created
4. Launch Dhilip Home Server like a normal Windows application
5. Uninstall from Windows Apps / Installed Apps

The standalone EXE is packaged with Python internally; Python is not required on the target machine.

The GitHub Actions workflow builds both the standalone EXE and the installable Setup EXE.
